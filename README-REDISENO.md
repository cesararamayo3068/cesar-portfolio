# Portfolio de César Aramayo — rediseño

Proyecto Angular 15.2 basado en el portfolio original, con diseño navy/cian/violeta, responsive y modo claro/oscuro persistente.

## Cómo usar

1. Descomprimir el ZIP en una carpeta nueva (recomendado para conservar una copia del portfolio actual).
2. Abrir CMD en `cesar-portfolio`.
3. Ejecutar `npm ci` (requiere Node.js compatible con Angular 15, preferentemente Node 18).
4. Ejecutar `npm start` y visitar `http://localhost:4200`.
5. Para compilar: `npm run build`.

La publicación actual no se modifica por entregar este archivo. Revisar el resultado local antes de hacer commit y desplegar.

## Proyectos

Commerce Platform incluye enlaces a demo y código. La vista del proyecto es una **ilustración CSS**, no una captura de pantalla real. Cuando tengas una captura del catálogo, se puede reemplazar la ilustración por la imagen.

## Notas

Se conservan los recursos de `src/assets`, incluida la foto y el PDF del CV, y la trayectoria profesional original. El título de formación superior se presenta como «Estudios cursados» para no afirmar una titulación no verificada. Se excluyen `node_modules`, `dist`, `.angular` y `.git` del ZIP para mantenerlo liviano.
